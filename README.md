# Portfolio Numérique — Daniel Ramiandrisoa

Portfolio numérique réalisé dans le cadre de l'épreuve **E5** — Développeur Web Full Stack.

🔗 **Site en ligne :** https://acemaneyeshild21.github.io/Portefolio/

## Contenu

- **Profil** — présentation et CV téléchargeable
- **Projets en formation** — Supercar (RP1), VMS / Pharmagest (RP2), Restoorder
- **Projets en entreprise** — stages 1ère et 2ème année
- **Tableau de synthèse** — récapitulatif des expériences et compétences
- **Compétences transversales** — gestion de projet, veilles, cybersécurité, etc.
- **Contact** — formulaire (ouvre votre messagerie) + liens

## Stack technique

HTML5 · CSS3 · JavaScript (vanilla) — site statique, sans dépendance de build.

## Structure

```
index.html        Page principale du portfolio
cv.html           Page CV (image)
assets/
  style.css       Styles (thème clair/sombre)
  controllers/
    script.js     Interactions (menu, scroll, reveal, formulaire)
IMAGES/           Photos et visuels
CV.pdf            CV au format PDF
```

## Déploiement

Le site est déployé automatiquement via **GitHub Pages** à chaque push sur `main`.
